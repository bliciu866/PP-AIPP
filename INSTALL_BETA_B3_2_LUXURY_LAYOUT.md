# PP-AIPP Beta B3.2 - Luxury Editorial Photo Layout

1. Close PP-AIPP.
2. Copy all files and folders from this package into the local `PP-AIPP` repository.
3. Allow Windows to replace files with matching names.
4. Commit and push with GitHub Desktop.
5. Download and extract the new Windows artifact after GitHub Actions succeeds.
6. Open the existing project and run Import Gold Master, Validate, Build Book and Export.

The main `*_Print.pdf` will contain a navy-and-gold cover, a collection opener,
alternating premium photography layouts, editorial cards and one recipe per page.

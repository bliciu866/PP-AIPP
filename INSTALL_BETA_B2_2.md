# Install Beta B2.2 into the PP-AIPP repository

1. Close PP-AIPP and GitHub Desktop.
2. Extract `PP-AIPP-v3.0.0-beta.6-B2.2-SOURCE.zip`.
3. Copy the extracted `PP-AIPP` folder contents into `C:\BLICIU\PP-AIPP`.
4. Confirm replacement of existing files.
5. Open GitHub Desktop and commit with summary
   `PP-AIPP v3.0.0-beta.6 B2.2 Premium Layout Image Engine`.
6. Push to `main` and wait for both workflows.
7. Download the `PP-AIPP-Windows-beta.6-B2.2` artifact.

# PP-AIPP Beta Desktop Framework

## Technology

The desktop application uses Python and PySide6 (Qt 6).

## Install

```bash
python -m pip install -e ".[desktop]"
```

## Start

```bash
pp-aipp-desktop
```

or:

```bash
pp-aipp desktop
```

## Beta B1.0 scope

- Main window
- Menu and toolbar
- Project Explorer
- Build Console
- Progress indicator
- Project and Gold Master selection
- Settings dialog
- Kernel lifecycle integration

Parser, validation, layout and export buttons are present as controlled integration
points. Full asynchronous execution is scheduled for the next Beta sprints.

# PP-AIPP Beta B2.3

1. Open the existing PP-AIPP project.
2. Select **Import Photos**.
3. Choose a folder containing images named `PP-R001.jpg` through `PP-R080.jpg`.
4. Review the import summary and `qa/photography_readiness_report.json`.
5. Select **Export** to rebuild the PDF with all available production images.

Recommended asset specification: portrait 4:5, minimum 1200 x 1500 pixels, licensed for commercial use.

# PP-AIPP B3.4.2 Layout QA Hotfix

This hotfix preserves runtime version `3.0.0b11` and corrects two issues found in
the first real Windows export review.

## Corrected

- Long recipe names now wrap inside the Breakfast, Lunch and Dinner columns of
  all five weekly programme pages.
- Recipe index entries retain complete titles instead of cutting them at a fixed
  character count.
- Each of the four indexes is split into three readable parts, producing a
  112-page final PDF with accurate contents navigation.

## Apply

Copy the contents of the included `PP-AIPP` folder over the repository root and
allow Windows to replace the matching files. Commit with:

`Fix B3.4 weekly plan and index layout`

Push `main`, wait for both GitHub Actions workflows to turn green, then download
the new Windows artifact and repeat Build Book and Export.

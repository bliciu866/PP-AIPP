# Install Beta B2 into the PP-AIPP repository

1. Close PP-AIPP and GitHub Desktop.
2. Extract `PP-AIPP-v3.0.0-beta.6-B2-SOURCE.zip`.
3. Copy the extracted `PP-AIPP` folder contents into `C:\BLICIU\PP-AIPP`.
4. Confirm replacement of existing files when Windows asks.
5. Open GitHub Desktop and review the Beta B2 changes.
6. Use commit summary `PP-AIPP v3.0.0-beta.6 B2 Export Engine`.
7. Commit to `main`, then select **Push origin**.
8. Wait for both GitHub Actions workflows to turn green.
9. Download the `PP-AIPP-Windows-beta.6-B2` artifact from the Windows workflow.

# Install PP-AIPP Beta B2.4 on Windows

1. Download the `PP-AIPP-Windows-beta.6-B2.4` artifact from GitHub Actions.
2. Extract the downloaded ZIP.
3. Extract `PP-AIPP-Windows-Portable.zip`.
4. Run `PP-AIPP.exe`.
5. Open the existing `30_Days_Fat_Loss` project.
6. Use **Import Photos** to add one or more prepared photo batches.

Previously imported recipe photographs remain in the project between batches.

# PP-AIPP B3.5 Final Brand & Cover Polish

B3.5 is the final visual-brand pass for the 30 Days Fat Loss publishing PDF.
It preserves runtime version `3.0.0b11` and the verified 112-page structure.

## Included

- Approved Project Physique cover with the green leaf mark and fitness hero image.
- Photo-led collection opener using three verified recipe photographs.
- White, Forest Green, Charcoal and Fresh Lime publishing identity.
- Branded information-page panels and footers.
- Consolidated shopping-list names and quantities.
- B3.4.2 weekly-plan wrapping and complete three-part indexes.
- Explicit PyInstaller and Python package inclusion for brand artwork and fonts.

## Apply

Copy the contents of the included `PP-AIPP` folder over the repository root and
allow Windows to replace the matching files. Commit with:

`PP-AIPP B3.5 Final Brand and Cover Polish`

Push `main`, wait for both GitHub Actions workflows to turn green, then download
`PP-AIPP-Windows-beta.11-B3.5`. Open the existing `project-physique` workspace,
select Gold Master v4.1, confirm photography coverage of 80/80, then Build Book
and Export.

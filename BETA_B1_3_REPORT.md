# PP-AIPP v3.0.0-beta.5 — Beta B1.3 Build Book Engine

- Connects the desktop `Build Book` action to the controlled Gold Master parser.
- Persists parsed recipes in the project SQLite database.
- Generates a production DOCX in the project `exports` directory.
- Writes Gold Master import and layout build reports to `qa`.
- Displays recipe and ingredient totals plus the exact output path.

# Install Beta B2.1 into the PP-AIPP repository

1. Close PP-AIPP and GitHub Desktop.
2. Extract `PP-AIPP-v3.0.0-beta.6-B2.1-SOURCE.zip`.
3. Copy the extracted `PP-AIPP` folder contents into `C:\BLICIU\PP-AIPP`.
4. Confirm replacement of existing files.
5. Open GitHub Desktop and review the B2.1 changes.
6. Commit with summary `PP-AIPP v3.0.0-beta.6 B2.1 PDF Publishing Pack`.
7. Push to `main` and wait for both GitHub Actions workflows.
8. Download the `PP-AIPP-Windows-beta.6-B2.1` Windows artifact.

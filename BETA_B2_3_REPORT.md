# Beta B2.3 — Photography Asset Pipeline

Adds a production photography workflow for recipe assets `PP-R001` through `PP-R080`.

- Bulk import from a selected folder.
- Automatic recipe assignment from filenames.
- JPEG, PNG and WebP support.
- 4:5 aspect-ratio and minimum-resolution checks.
- Duplicate, invalid-name and unreadable-file rejection.
- Persistent `qa/photography_readiness_report.json`.
- Photography readiness report included in verified export packages.
- Existing PDF placeholder remains active until a licensed asset is supplied.

Accepted names include `PP-R001.jpg` and `PP-R001_hero.png`.

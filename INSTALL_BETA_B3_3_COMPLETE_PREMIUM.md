# PP-AIPP B3.3 Complete Premium Programme

1. Close PP-AIPP and GitHub Desktop.
2. Extract this ZIP.
3. Copy every extracted file into the local `PP-AIPP` repository and confirm replacement of matching files.
4. Open GitHub Desktop and commit all changed files with:
   `PP-AIPP B3.3 Complete Premium Programme`
5. Push to `main` and wait for both GitHub Actions workflows to turn green.
6. Download and extract the new Windows artifact, then start `PP-AIPP.exe`.
7. Open the existing Project Physique project.
8. Import the v6 Luxury Editorial Master DOCX, then click `Validate`.
9. Import the prepared 80-photo folder if the project does not already report 80/80 coverage.
10. Click `Build Book`, then `Export`.

The final PDF should contain 105 pages and the photography report should show
80 recipes, 80 images found and 0 missing.

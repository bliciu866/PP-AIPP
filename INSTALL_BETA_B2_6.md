# Install Beta B2.6

1. Open GitHub Actions and select the newest Windows EXE workflow run.
2. Download `PP-AIPP-Windows-beta.6-B2.6` from Artifacts.
3. Extract the downloaded ZIP completely.
4. Run `PP-AIPP.exe` from `PP-AIPP-Windows-Portable`.
5. Open the existing `30_Days_Fat_Loss` project.
6. Click `Prepare Photo Batch` and choose the desired batch size (default: 10).
7. Add the requested photographs to the created batch folder using the exact filenames from `PHOTO_BATCH_MANIFEST.csv`.
8. Return to PP-AIPP and click `Import Photos`, then select the batch folder.
9. Build and export the book to update photography coverage.

The planner creates batch folders inside the project `photo_batches` directory. Accepted photograph formats are JPG, JPEG, PNG, and WebP.

# B3.6.2 Fast and Reliable CI Hotfix

This overlay prevents an unavailable Python 3.13 runner from blocking the
mandatory release pipeline.

## Changes

- Python 3.11 and 3.12 remain the mandatory push and pull-request quality gate.
- Python 3.13 moves to a separate, manually triggered compatibility workflow.
- Checkout, Python setup and artifact upload actions use Node.js 24 releases.
- Jobs have explicit time limits.
- Windows builds use concurrency cancellation, matching the quality workflow.

## Install

Copy the included `PP-AIPP` directory over the repository root, preserving the
`.github` directory, then commit and push all included files. The corrected
Ruff import order test from B3.6.1 is included again for a self-contained patch.

Suggested commit message:

`Optimize B3.6 CI and move Python 3.13 to manual compatibility`

The old queued workflow may be cancelled. The next push automatically starts
the two-version mandatory quality gate and the Windows build. Run the optional
Python 3.13 workflow from Actions only when compatibility verification is
needed.

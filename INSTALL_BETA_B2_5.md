# Install Beta B2.5

1. Open GitHub Actions and select the newest Windows EXE workflow run.
2. Download `PP-AIPP-Windows-beta.6-B2.5` from Artifacts.
3. Extract the downloaded ZIP completely.
4. Run `PP-AIPP.exe` from `PP-AIPP-Windows-Portable`.
5. Open the existing `30_Days_Fat_Loss` project.
6. Import recipe photographs in named batches using `Import Photos`.

Photography filenames must use `PP-R001.jpg` through `PP-R080.jpg` (PNG and WebP are also accepted).
